LiemLegacy | 2D Metroidvania Action Game
LiemLegacy is a passion-driven 2D action game built from the ground up using Unity and C#. This project serves as a primary showcase of my technical expertise in game logic architecture, AI systems, and responsive gameplay mechanics.

**Technical HighlightsCustom**
Character Controller: Engineered precise, frame-by-frame movement and combat logic to ensure a fluid and responsive "game feel".  NPC Intelligence (AI): Designed and implemented complex enemy behaviors using Finite State Machines (FSM). This allows NPCs to dynamically patrol, track, and engage the player based on proximity and line-of-sight.  Data Persistence System: Developed a robust save/load architecture using file-based serialization to handle character coordinates, unlocked abilities, and world states.  UI/UX Integration: Built an interactive Inventory and Ability system (including mechanics like Dash and Double Jump) using Unity's Canvas and Event Systems.  Performance Optimization: Managed object life cycles and memory usage to maintain stable frame rates during intensive combat sequences. 

**Game Design**
My journey with this game was one of constant learning and refinement. I spent countless hours perfecting the Character Controller to ensure that every jump and strike feels fluid and responsive, aiming for that perfect "game feel" that keeps players engaged. Beyond the mechanics, I took pride in architecting the NPC Intelligence using Finite State Machines (FSM), giving life to enemies that don't just stand still, but actively hunt and challenge the player.
