## 📖 Overview
**LiemLegacy** is a passion-driven 2D action game built from the ground up using **Unity and C#**. This project serves as the primary showcase of my technical expertise in game logic architecture, AI systems, and responsive gameplay mechanics.

> **Developer's Heart:** My journey with this game was one of constant learning and refinement. I spent countless hours perfecting the **Character Controller** to ensure every jump and strike feels fluid, aiming for that perfect "game feel" that keeps players engaged. Beyond the mechanics, I took pride in architecting the NPC Intelligence, giving life to enemies that actively challenge the player.

---

## 🛠️ Technical Highlights

| Feature | Technical Description |
| :--- | :--- |
| **Custom Character Controller** | Engineered precise, frame-by-frame movement and combat logic for a fluid and responsive experience. |
| **NPC Intelligence (AI)** | Implemented complex enemy behaviors using **Finite State Machines (FSM)** for dynamic patrolling and tracking. |
| **Data Persistence** | Developed a robust save/load architecture using **file-based serialization** for coordinates and world states. |
| **UI/UX Integration** | Built interactive Inventory and Ability systems (Dash, Double Jump) using **Unity Canvas & Event Systems**. |
| **Performance** | Managed object life cycles and memory usage to maintain stable frame rates during intensive combat. |

## 🏗️ Architecture & Tech Stack

### **Core Architecture**
*   **Finite State Machine (FSM):** Used to create intelligent NPCs that patrol, track, and engage based on line-of-sight.
*   **Object-Oriented Programming (OOP):** Applied to ensure clean, maintainable, and scalable code structures.

### **Toolbox**
*   **Engine:** Unity (C#)
*   **Version Control:** Git
*   **Logging:** JSON Logging for system data tracking and debugging

---

## 🚀 Getting Started

### **Prerequisites**
*   **Unity Editor**: Version `6000.0.32f1` or later is recommended.

### **Installation & Play**
1.  **Clone** this repository to your local machine.
2.  Open the project folder via **Unity Hub**.
3.  Navigate to `Assets/Scenes` and open either **Cave_1** or **Menu**.
4.  Press the **Play** button to start the experience.
